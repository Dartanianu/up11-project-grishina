# Сумки и аксессуары

**ФИО:** Гришина Дарья Викторовна
**Группа:** 3ИП-1-24

## Описание
Приложение на Python (PySide6) для просмотра каталога товаров. Работает с базой данных PostgreSQL. Есть роли (админ, менеджер, клиент), поиск, фильтрация, сортировка и автоматическая скидка 25% на товары без заказов в этом месяце.

## Как запустить проект

**1. Создайте виртуальное окружение**
Откройте терминал в папке с проектом и введите:

python -m venv venv

**2. Активация виртуального окружение**
В том же терминале введите:

### Для Windows
venv\Scripts\activate

### Для macOS/Linux
source venv/bin/activate

**3. Установка библиотек**
В папке проекта находится файл requirements.txt, пропишите в терминал:

pip install -r requirements.txt

**4. Настройте базу данных**
В файле main.py прокрутите файл в самый конец, измените Логин и Пароль PostgreSQL

**5. Запустите приложение**
Введите в терминал:

python main.py
